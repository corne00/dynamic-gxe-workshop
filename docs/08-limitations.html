8 · Limitations

Choice of library

The same pipeline is applied to leaf area index (LAI), which rises and then falls during the season, by changing var = "lai".

trl <- make_trajectories(traj, drv, var = "lai")
cv_poly <- cv_blocked(Theta, trl, gram_stats(Theta, trl), fit_ols)

As an alternative library, a B-spline basis in thermal time with the other three drivers entering linearly:

B <- bs(as.vector(drv$U[, , "TT"]), df = 6)
Theta_spl <- array(cbind(1, B, matrix(drv$U[, , -1], ncol = 3)), c(dim(drv$U)[1:2], 10))
cv_spl <- cv_blocked(Theta_spl, trl, gram_stats(Theta_spl, trl), fit_ols)

base <- lookup_trajectory(trl)
rbind(`cubic polynomial` = evaluate(cv_poly$pred, trl), `B-spline in TT` = evaluate(cv_spl$pred, trl), baseline = evaluate(base, trl)) |> round(3)
                 trajectory_rmse fixed_day_rmse maturity_rmse
cubic polynomial           0.885          1.212         0.972
B-spline in TT             0.526          0.664         0.539
baseline                   0.473          0.687         0.637
models <- c("cubic polynomial", "B-spline in TT", "baseline"); days <- 2:dim(trl$Y)[3] + trl$das0 - 1
d <- do.call(rbind, Map(function(P, m) data.frame(das = days, rmse = rmse_by_day(P, trl), model = m),
                        list(cv_poly$pred, cv_spl$pred, base), models))
ggplot(d[d$das <= 155, ], aes(das, rmse, colour = factor(model, models))) + geom_line(linewidth = 0.8) +
  scale_colour_manual(values = unname(dgxe[c("burgundy", "blue", "grey")])) +
  labs(x = "days after sowing", y = "held-out LAI RMSE") + theme_dgxe() + theme(legend.position = "top", legend.title = element_blank())

A cubic polynomial in the standardised drivers cannot represent the rise and fall of LAI, and its error is larger than that of the baseline throughout. The spline library is considerably better, but over whole trajectories the baseline remains slightly more accurate (0.47 against 0.53); the spline model is better at day 113 and at maturity. When the model is inaccurate, the library should be examined before the fitting method.

Collinear drivers

Thermal time and day length have a correlation of 0.97. Fitting the same model separately to odd and even seasons gives different coefficients but nearly identical growth rates.

fit_half <- function(years) fit_years(gram, which(tr$years %in% years), fit_ols)$mu
mu_odd <- fit_half(tr$years[tr$years %% 2 == 1]); mu_even <- fit_half(tr$years[tr$years %% 2 == 0])
coefs <- cbind(odd = mu_odd, even = mu_even); rownames(coefs) <- gram$names
round(coefs[c("TT", "TT^2", "DL", "DL^2"), ], 3)
        odd   even
TT   -0.063 -0.037
TT^2 -0.036 -0.031
DL    0.045  0.020
DL^2 -0.055 -0.051
Tbar <- apply(Theta, c(2, 3), mean)                      # library along the mean weather path
rate_odd <- Tbar %*% mu_odd; rate_even <- Tbar %*% mu_even
c(correlation = cor(rate_odd, rate_even), max_difference = max(abs(rate_odd - rate_even)))
   correlation max_difference 
   0.998197498    0.009107564

The data determine the combined effect of correlated drivers better than each coefficient, so response curves are preferable to individual coefficients for interpretation.

Accumulation of error

The regression is performed on daily increments, whereas the prediction is their cumulative sum. A small bias in the daily increment therefore accumulates.

cv <- cv_blocked(Theta, tr, gram, fit_ssr, k = 12)
increment_error <- unlist(lapply(seq_along(tr$genotypes), function(g) lapply(seq_along(tr$years), function(y) {
  n <- tr$nend[g, y]; diff(cv$pred[g, y, 1:(n + 1)]) - trajectory_xz(Theta, tr, g, y)$z })))
c(daily_increment_rmse = sqrt(mean(increment_error^2)), trajectory_rmse = evaluate(cv$pred, tr)[[1]])
daily_increment_rmse      trajectory_rmse 
          0.02801567           0.52096960

For this reason the model is assessed on the simulated trajectory and not on the daily increments.
