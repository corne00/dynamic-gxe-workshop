8 · Build your own model

Choose the modelled states, the drivers, the library and the fitting method, and see the resulting equations and their prediction for years that were left out of the fit. The calculations run in the browser and follow the functions of the previous steps: each genotype is fitted to all years for the coefficients, and leave-one-year-out validation gives the held-out error.

With one modelled state \(y\) (biomass or LAI) the model is \(\dot{y} = \boldsymbol{\xi}^{\top}\boldsymbol{\theta}(\mathbf{u})\) with weather drivers \(\mathbf{u}\). With state feedback the modelled states enter the library as well, \(\dot{y}_k = \boldsymbol{\xi}_k^{\top}\boldsymbol{\theta}(\mathbf{u}, y_1, y_2)\), and with both states modelled the two equations form a coupled system with a coefficient vector \(\boldsymbol{\xi}_k\) each. States are standardised like the drivers, and with products the library also contains state × state and state × driver terms. The coupled system is integrated over the held-out year; a year whose solution grows beyond ten times the largest observed value counts as diverged and is left out of the error. In our tests, feedback was typically not better than weather-only models and can be unstable.

Extra terms are functions of the raw weather. Each line adds one term to the library, standardised like the drivers: write name = expression, or click an example. The variables are Tmin, Tmax, Rain, RAD, VP, DL, TT, RAW, Tmean, VPD (vapour pressure deficit, from Tmax and VP), das (days after sowing) and, with the measured input switched on, lai or biomass. The operators are + - * / ^, and the functions are exp, log, sqrt, abs, sin, cos, tan, tanh, min and max (elementwise), roll(x, k) (mean of the last k days), cum(x) and lag(x, k).

code = {
  const f = v => (v === null ? "" : `${+(+v).toPrecision(3)}`);
  const call = {
    OLS: ["fit_ols", () => "", () => ""],
    ridge: ["fit_ridge", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    lasso: ["fit_lasso", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    "elastic net": ["fit_enet", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    "best subset": ["fit_subset", v => `, k = ${f(v)}`, v => `, k=${f(v)}`],
    backward: ["fit_subset", v => `, k = ${f(v)}, method = "backward"`, v => `, k=${f(v)}, method="backward"`],
    STLSQ: ["fit_stlsq", v => `, threshold = ${f(v)}`, v => `, threshold=${f(v)}`]
  }[method];
  const v = spec.values[step];
  const rArgs = call[1](v), pyArgs = call[2](v);
  const rDrivers = `c(${drivers.map(d => `"${d}"`).join(", ")})`;
  const pyDrivers = `[${drivers.map(d => `"${d}"`).join(", ")}]`;
  const pairs = products === "yes";
  const tr = traitName ? `"${traitName}"` : null;
  const rLoad = tr ? `wg <- with_traits(wx, traj, "${genotype}", ${tr})\n` : "";
  const pyLoad = tr ? `wg = with_traits(wx, traj, "${genotype}", [${tr}])\n` : "";
  const W = tr ? "wg" : "wx";
  const single = stateList.length === 1 && !feedback;
  const rTarget = stateList[0] === "lai" ? `, "lai"` : "";
  const pyTarget = stateList[0] === "lai" ? `, "lai"` : "";
  const F = feedback ? "TRUE" : "FALSE", PF = feedback ? "True" : "False";
  const P = pairs ? "TRUE" : "FALSE", PP = pairs ? "True" : "False";
  const rTrs = `trs <- list(${stateList.map(k => `${k} = make_trajectories(traj, drv, "${k}")`).join(",\n            ")})`;
  const pyTrs = `trs = {${stateList.map(k => `"${k}": make_trajectories(traj, drv, "${k}")`).join(",\n       ")}}`;
  const rExtra = extras.length ? `
extra <- extra_terms(${W}, c(${extras.map(e => `${e.name} = "${e.expr}"`).join(",\n                           ")}))
Theta <- bind_terms(Theta, extra)` : "";
  const pyExtra = extras.length ? `
extra = extra_terms(${W}, {${extras.map(e => `"${e.name}": "${e.expr}"`).join(",\n                         ")}})
Theta = bind_terms(Theta, extra)` : "";
  if (!single) return {
    r: `${rLoad}drivers <- ${rDrivers}
drv <- make_drivers(${W}, drivers)
Theta <- make_library(drv, degree = ${degree}, pairs = ${P})${rExtra}
${rTrs}
fit <- function(X, dy) ${call[0]}(X, dy${rArgs})

d <- make_design_states(Theta, trs, "${genotype}", drivers, ${degree}, ${P}, ${F})
coef <- lapply(seq_along(trs), function(k) fit(d$X, d$dy[, k]))

Best subset is offered only for libraries with a small number of subsets; backward elimination approximates it for larger libraries. With one modelled state and no feedback, the other state may enter the right-hand side as a measured input; the prediction of a held-out year then uses its measured values, so this is not a forecast. With both states modelled, nothing measured is used beyond the initial values.
