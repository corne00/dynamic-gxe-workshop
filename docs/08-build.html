8 · Build your own model

Choose the modelled state, the drivers, the library and the fitting method, and see the resulting equation and its prediction for years that were left out of the fit. The calculations run in the browser and follow the functions of the previous steps: the genotype is fitted to all years for the coefficients, and leave-one-year-out validation gives the held-out error.

d3 = window.d3
Plot = window.Plot
builder = FileAttachment("data/interactive/builder.json").json()
palette = ["#014E81", "#00A6D6", "#8B1E3F", "#469C2A", "#6F1D77", "#EF60A3", "#00A390", "#6B7280"]

Extra terms are functions of the raw weather. Each line adds one term to the library, standardised like the drivers: write name = expression, or click an example. The variables are Tmin, Tmax, Rain, RAD, VP, DL, TT, RAW, Tmean, VPD (vapour pressure deficit, from Tmax and VP), das (days after sowing) and, with the measured input switched on, lai or biomass. The operators are + - * / ^, and the functions are exp, log, sqrt, abs, sin, cos, tan, tanh, min and max (elementwise), roll(x, k) (mean of the last k days), cum(x) and lag(x, k).

{
  if (result.error) return html``;
  const kept = result.terms.map((term, i) => ({term, effect: result.scaled[i]})).filter(d => d.effect !== 0);
  const reach = d3.max(kept, d => Math.abs(d.effect)) || 1;
  const coefficients = Plot.plot({

  const scatter = Plot.plot({

The same model in R and Python

The choices above correspond to the following calls, with wx and traj loaded as in step 2.

code = {
  const f = v => (v === null ? "" : `${+(+v).toPrecision(3)}`);
  const call = {
    OLS: ["fit_ols", () => "", () => ""],
    ridge: ["fit_ridge", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    lasso: ["fit_lasso", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    "elastic net": ["fit_enet", v => `, lambda = ${f(v)}`, v => `, lam=${f(v)}`],
    "best subset": ["fit_subset", v => `, k = ${f(v)}`, v => `, k=${f(v)}`],
    backward: ["fit_subset", v => `, k = ${f(v)}, method = "backward"`, v => `, k=${f(v)}, method="backward"`],
    STLSQ: ["fit_stlsq", v => `, threshold = ${f(v)}`, v => `, threshold=${f(v)}`]
  }[method];
  const v = spec.values[step];
  const rArgs = call[1](v), pyArgs = call[2](v);
  const rDrivers = `c(${drivers.map(d => `"${d}"`).join(", ")})`;
  const pyDrivers = `[${drivers.map(d => `"${d}"`).join(", ")}]`;
  const pairs = products === "yes";
  const tr = traitName ? `"${traitName}"` : null;
  const rLoad = tr ? `wg <- with_traits(wx, traj, "${genotype}", ${tr})\n` : "";
  const pyLoad = tr ? `wg = with_traits(wx, traj, "${genotype}", [${tr}])\n` : "";
  const W = tr ? "wg" : "wx";
  const rTarget = stateKey === "lai" ? `, "lai"` : "";
  const pyTarget = stateKey === "lai" ? `, "lai"` : "";
  const rExtra = extras.length ? `
extra <- extra_terms(${W}, c(${extras.map(e => `${e.name} = "${e.expr}"`).join(",\n                           ")}))
Theta <- bind_terms(Theta, extra)` : "";
  const pyExtra = extras.length ? `
extra = extra_terms(${W}, {${extras.map(e => `"${e.name}": "${e.expr}"`).join(",\n                         ")}})
Theta = bind_terms(Theta, extra)` : "";
  return {
    r: `${rLoad}drv <- make_drivers(${W}, ${rDrivers})
Theta <- make_library(drv, degree = ${degree}, pairs = ${pairs ? "TRUE" : "FALSE"})${rExtra}
tr <- make_trajectories(traj, drv${rTarget})
fit <- function(X, dy) ${call[0]}(X, dy${rArgs})

d <- make_design(Theta, tr, "${genotype}")
coef <- fit(d$X, d$dy)
P <- cross_validate(Theta, tr, fit, "${genotype}")
evaluate(P, tr)`,
    py: `${pyLoad}drv = make_drivers(${W}, ${pyDrivers})
Theta = make_library(drv, degree=${degree}, pairs=${pairs ? "True" : "False"})${pyExtra}
tr = make_trajectories(traj, drv${pyTarget})

def fit(X, dy):
    return ${call[0]}(X, dy${pyArgs})

d = make_design(Theta, tr, "${genotype}")
coef = fit(d.X, d.dy)
P = cross_validate(Theta, tr, fit, ["${genotype}"])
print(evaluate(P, tr))`};
}

Best subset is offered only for libraries with a small number of subsets; backward elimination approximates it for larger libraries. Only one state is modelled at a time: the other state may enter the right-hand side as a measured input, so the prediction of a held-out year uses its measured values and the model is not a coupled system for both states.
