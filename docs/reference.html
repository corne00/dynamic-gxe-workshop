Reference

Symbols, functions, data, and sources

Symbols

Symbol Meaning
\(\mathbf{y}(t)\), \(y\) state of the crop; here biomass (t/ha)
\(\mathbf{u}(t) = (u_1, \dots, u_m)\) environmental drivers, standardised
\(\theta_j(\mathbf{y}, \mathbf{u})\) candidate function \(j\) of the library
\(\boldsymbol{\theta}\) vector of all candidate functions
\(\boldsymbol{\xi}\) coefficient vector
\(\dot y_i \approx (y_i - y_{i-1}) / \Delta t\), \(\dot{\mathbf{y}}\) growth rate of day \(i\) by the one-day difference (centered at the middle of the day), and the vector of growth rates
\(\mathbf{X}\) library evaluated on all days (rows)
\(K\) number of candidate functions

Functions

All functions are in R/functions.R (R) and python/dgxe.py (Python), with the same names and arguments.

Function Purpose
make_drivers(wx) standardised drivers U[year, day, driver]
make_library(drv, degree, pairs) library Theta[year, day, term]
extra_terms(wx, exprs), bind_terms(Theta, extra) extra library terms from expressions of the raw weather
with_traits(wx, traj, genotype, vars) adds measured states ("lai", "biomass") to the weather as day series, so they can be drivers or appear in expressions
make_trajectories(traj, drv, var) response Y[genotype, year, day]
make_design(Theta, tr, genotype) design matrix X and growth rates dy (one-day differences)
fit_ols, fit_ridge, fit_lasso, fit_enet, fit_subset, fit_stlsq fitting methods fit(X, dy)
simulate(coef, U, y0) solution of the fitted equation with an ODE solver
cross_validate(Theta, tr, fit) leave-one-year-out predictions
make_design_states(Theta, trs, genotype, drivers, degree, pairs, feedback) design with state terms (state_terms) and one column of dy per modelled state; trs is a list of trajectory sets, one per state
simulate_states(coef, U, y0, terms) solution of the coupled system; years that blow up are returned as NA
cross_validate_states(Theta, trs, fit, genotypes, drivers, degree, pairs, feedback) leave-one-year-out predictions of the (coupled) model, one P per state, and the number of diverged years
evaluate(P, tr) trajectory, fixed-day and maturity RMSE
ale_curve(rate, Z, j) accumulated local effect of driver j
rank_scores(Pd, Yd) ranking metrics

The R and Python versions differ only in conventions: R uses TRUE/FALSE and 1:n indexing, Python uses True/False, zero-based indexing and the attribute syntax tr.Y instead of tr$Y.

Data

APSIM wheat simulations at Narrabri (New South Wales, Australia): 199 genotypes, 31 years (1983 to 2013), daily. Columns are described in Data. Files are in data/.
